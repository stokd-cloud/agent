### Import/export format oracle
A local dry run writes a versioned JSON manifest containing source root, category/parser version, each selected file's size/hash, proposed destination/type, excluded reasons, detected secret review, source-to-destination links and duplicate/conflict policy. It does not create an import record or upload bytes. Apply reads that manifest by path, rejects changed sources/unreviewed entries, creates an import ID and commits only verified batches. No source file is modified or removed.

| Declared input | Exact MVP treatment |
|---|---|
| `legacy-md-v1` | `IDENTITY.md` proposes identity text; `SOUL.md` proposes perspective; `USER.md` proposes preferences; `MEMORY.md` and explicitly selected `memory/*` propose sourced facts. Owner reviews mappings before activation. `AGENTS.md`, `TOOLS.md`, `TASKS.md`, routines and unknown instructions are inert source documents unless the owner selects a supported non-executable field. They never activate tools, schedules or peers. |
| `legacy-stokd-meta-v0` | JSONL records must contain epoch, model, modelVersion, prompt and response with declared scalar/string types. Preserve them as `legacy_exchange` records with source file/offset/hash and original fields. Do not invent human-chat provenance or dates; only unambiguous validated source timestamps map to event time. |
| Telemetry/signals/unknown JSONL | Telemetry `.stokd/sessions`, `.claude-sessions` signals, malformed/unknown schemas remain inert archive/exclusion entries, never invented chat history. |
| Arbitrary documents/media | Explicitly selected inert objects; preserve bytes, MIME and SHA-256. Scripts/HTML are attachments, never executable skills. Credentials, logs, caches, model weights, dependency trees and nested repositories are excluded by default and reported. |
| Native `agent-export-v1` | A gzip tar archive with `manifest.json`, typed `db/*.jsonl` and `objects/<artifactId>/<versionId>/<safeFilename>`. Manifest declares schema versions, lengths/digests, exported IDs and reference relations. Validate every record/link/hash before publication; importing as a new agent remaps domain IDs while preserving original provenance and version relationships. |

Native exports contain profile revisions, conversations/events, memory/tombstones, commitments, work receipts, artifact metadata/selected object versions and import provenance. Exclude sessions/tokens, host paths/secrets, pending bearer grants and provider-native caches. Running work is exported as observed status/receipt, never as restart authority. Export records one consistent database snapshot plus pinned object-version IDs; missing bytes or inconsistent references fail visibly.

Only the native format is unpacked by this importer. Reject absolute/traversal paths, duplicate entries, symlinks/hardlinks, nested extraction, declared/actual length mismatch and decompression bombs. General ZIP/TAR files are inert documents. Stream archive content with a 64 MiB buffer ceiling, 50 GiB expanded archive ceiling and existing 5 GiB/object plus agent quota checks; no whole-file buffering. A selected 2 GiB media fixture must stream successfully when within quota. Source/derivation tombstones accompany forget and export/import so retained source material cannot automatically recreate a forgotten memory without explicit owner restoration/new instruction.
